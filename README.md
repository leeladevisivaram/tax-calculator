# India Income Tax Calculator

Explainable local income-tax calculator for supported Indian individual/HUF scenarios. The app combines a guided browser UI, a Node.js tax API, rulepack-backed calculations, import preview, report generation, privacy controls, and a local app-help chatbot.

Built by D Siva Kumar with help from the CodeBasics Team.

## What This App Does

- Calculates supported Indian income-tax scenarios for AY 2025-26 and AY 2026-27.
- Supports old-regime and new-regime comparison.
- Guides users through Profile, Imports, Income, Deductions, Credits, Results, and Readiness.
- Supports salary, house property, other sources, capital gains, and business/profession inputs.
- Imports supported CSV, JSON, and searchable Form 16 PDF files through a preview-and-confirm flow.
- Produces explainable results with warnings, assumptions, rulepack metadata, source trace, and downloadable JSON/HTML reports.
- Includes a local chatbot for app navigation, supported actions, and calculator help.
- Keeps draft workflow data local to the browser unless the user exports or downloads a report.

## Usage Guide

1. Open the app and choose a start path from the Start screen.
2. Use the Calculator tab to move through the guided sections.
3. Complete Profile first: period, taxpayer type, residency, age, and preferred regime.
4. Use Imports if you have supported CSV, JSON, or searchable Form 16 PDF data.
5. Fill Income heads that apply to the scenario.
6. Add Deductions and Credits such as Chapter VI-A claims and TDS.
7. Go to Results and run:
   - Validate
   - Compute
   - Compare
   - Explain
8. Download JSON or HTML reports after Explain is generated.
9. Use the Chat button for app-help questions and supported form actions.
10. Use Privacy controls to view policy details, export local data, or delete local browser-held data.

## Main App Areas

- Start: Choose a scenario path such as salaried, investor, freelancer, senior citizen, tax professional, Form 16/PDF import, or regime comparison.
- Calculator: The main wizard for profile, imports, income, deductions, credits, results, and readiness.
- Guide: In-app help for each calculator section and user level.
- About: Coverage, official sources, builder note, data storage behavior, and privacy posture.
- Chat: Local calculator assistant for navigation, Q&A, and supported actions.

## Supported Import Flow

The Imports section supports:

- CSV files.
- JSON files.
- Searchable Form 16 PDF files.

The app previews mapped values before applying them. Apply import requires user confirmation, so imported values are not silently written into the form.

## Privacy And Data Storage

This is a local-first app.

- Browser `localStorage` can store draft form values, selected start path, checklist state, saved what-if scenarios, dismissed review notes, and AI review context.
- Import previews create local encrypted artifact metadata with retention information.
- Downloaded JSON/HTML reports are generated only when the user requests them.
- Chatbot interaction logs are local JSON Lines records and redact PAN, Aadhaar, email, and phone-like values.
- The local Node server keeps masked development audit events and route metrics.
- There is no account login, cloud sync, or share-link feature in this local version.

## Deploying Or Pushing To GitHub

### Vercel

The project uses Vite to build the React bundle into `public/react`, while the main static site already lives in `public/`. `vercel.json` sets Vercel's output directory to `public`, so Vercel should not look for a `dist/` folder.

The `api/` folder adapts the existing Node HTTP server to Vercel serverless functions:

- `/api/v1/*` is handled by `api/v1/[...path].js`.
- `/health` is rewritten to `api/health.js`.
- Local audit logs and chatbot interaction logs use temporary serverless storage on Vercel and are not durable there.

For a full project repository, include the source, docs, and tests.

For a lean runtime repository, the app can run without `docs/` and `testing/`, but test commands and test reports will not work unless those folders are included or the scripts are adjusted.

Minimum runtime folders and files:

```text
client/
data/
public/
scripts/
src/
api/
vercel.json
package.json
package-lock.json
vite.config.mjs
```

Recommended repository contents:

## Limitations

- This app is an explainable local estimate, not an income-tax filing product.
- It does not connect to AIS, TRACES, bank accounts, or the income-tax portal.
- It does not provide account login, cloud sync, or share links.
- Unsupported tax situations should be reviewed with a qualified tax professional before filing.
