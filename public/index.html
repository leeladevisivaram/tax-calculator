Application guide

How to use each part of the calculator

Follow these pages from profile to results. Enter only values that apply to your scenario, use 0 when an amount is not claimed, and review missing-entry messages before running an action.

Components

What the main areas do

  • Stepper moves between pages such as Profile, Imports, Income, Deductions, Credits, Results, and Readiness.
  • Form cards collect one group of inputs at a time. Required dropdowns should always keep a selected value.
  • Action bar runs preview, apply, validate, compute, compare, explain, report, save, and reset actions.
  • Scenario summary stays beside the form on desktop and shows the selected year, regime, income, and latest payable/refund state.
  • Output panels show import reviews, validation messages, results, comparisons, reports, privacy notices, and readiness responses.
User paths

Choose the path that matches your comfort level

  • No tax knowledge: start with Profile, keep supported defaults where correct, enter Age and regime, then move page by page. Keep unknown amounts as 0 instead of guessing.
  • Beginner: for a salary case, enter Gross salary in Income, claimed deductions in Deductions, TDS in Credits, then run Validate, Compute, Compare regimes, and Explain.
  • Intermediate: select all relevant income heads, review deduction availability by regime, use Compare regimes, and read warnings before relying on the result.
  • Advanced: review the worksheet, computation hash, source register, assumptions, special-rate rows, and JSON report after running Explain.
  • Unavailable features: automatic AIS prefill, account login, cloud sync, and share links are not active in this local app.
Profile

Taxpayer profile

Choose Period type, Period, Act, Taxpayer type, Residency, Age, Display language, and Preferred regime.

  • Use Assessment year unless your workflow asks for Tax year.
  • Enter age as a whole number, for example 34, 61, or 81.
  • Use privacy controls here to view policy text, export local data, or delete local data from this browser.
Imports

Import review

Select the import type, upload a CSV, JSON, or searchable Form 16 PDF file, preview it, then confirm before applying values.

  • Upload supported CSV, JSON, or searchable Form 16 PDF files when available; the app reads extracted values into the review box before preview.
  • Preview import checks pasted data without changing the form.
  • Apply import requires the Import review confirmation checkbox.
  • Unsupported import options appear inactive until integration support exists.
Income

Income heads

Tick the income heads that apply, then fill the visible cards for salary, house property, other sources, capital gains, or business.

  • Enter gross salary, HRA, rent, LTA, interest, gain, receipt, or turnover values as annual INR amounts.
  • Use 0 for fields that do not apply instead of leaving selected income-card amounts blank.
  • Use Add asset row and Delete row for capital-gains row management.
Deductions

Deductions and exemptions

Keep standard deduction checked when applicable and enter only claimed Chapter VI-A, rent, or housing-loan deduction amounts.

  • Use 0 for 80C, 80D, 80GG, 80EE, or 80EEA when there is no claim.
  • Tick Parent is senior citizen only when the parent medical premium claim needs senior-citizen treatment.
  • Validation messages explain if a deduction is unavailable for the chosen regime.
Credits

Taxes already paid

Enter TDS, TCS, advance tax, and self-assessment tax amounts already paid or shown in your records.

  • Use annual INR values from Form 16, AIS, challans, or other records.
  • Enter 0 when a credit category is not available.
  • Negative credit values are not accepted by the form.
Results

Results and explanation

Run Validate first, then Compute, Compare regimes, and Explain. Report downloads are available after an explanation is generated.

  • Validate checks required profile fields and visible scenario inputs.
  • Compute updates the result cards and scenario summary.
  • Compare regimes shows old and new regime cards for the same inputs.
  • Explain creates the Generated explanation report required for JSON and HTML report downloads.
Readiness

Operational readiness

Use readiness actions to view beta-plan, regression, release-readiness, and support responses, then classify feedback when needed.

  • Choose a category and severity or leave them on Auto when the app should classify the feedback.
  • Enter a clear feedback description before using Classify feedback.
  • Readiness messages are operational guidance and do not change calculator inputs.
What missing-entry messages mean
Profile actions

Validate, Compute, Compare regimes, and Explain cannot run when Period type, Period, Act, Taxpayer type, Residency, Age, or Regime is missing. Example: Validate cannot run because Age is missing.

Import actions

Preview import needs Import type, Filename, and CSV, JSON, or extracted PDF content. Apply import also needs Import review confirmation. Example: Apply import cannot run because Import review confirmation is missing.

Report actions

JSON report and HTML report cannot run until Generated explanation report is available from the Explain action. Example: JSON report cannot run because Generated explanation report is missing.

Feedback action

Classify feedback cannot run when Feedback is missing. Enter the issue or observation in the Feedback box first.

Amount fields

If the browser says a field must be zero or more, replace the negative value with 0 or a valid positive INR amount.

Setup message

Application setup incomplete means a required page element or button is missing from the loaded app shell.
